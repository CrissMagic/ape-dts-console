# 用户体验修复验收（2026-09-10）

## 已实现

- 首页和任务空页提供“配置数据源 → 验证连接 → 创建任务 → 首次运行”的配置指南。明确标注页面新建任务尚未开放，不将配置顺序展示为已完成状态。任务列表读取失败与无可访问任务分开呈现。
- 数据源新建、编辑草稿在切换菜单、退出登录、重置表单、选择其他数据源前提示确认。取消离开保留草稿，明确放弃才清空。刷新或关闭窗口通过浏览器原生离开提醒保护。密码不写入 localStorage、sessionStorage 或其他浏览器缓存。
- 数据源与用户管理确认改为 Ant Design 弹窗，保留风险勾选与忙碌状态禁用。数据源确认显示名称、类型与目标地址；错误在弹窗内可见。再认证时让出界面，不自动执行原操作。
- 数据源地址解释平台容器网络视角；TLS选项增加中文含义，连接凭据文案去除实现术语，并设置表单自动填充提示。
- 导航分为同步工作与系统安全，审计菜单提前标注未开放，顶部“平台就绪”改为“管理服务正常”。
- 用户列表显示中文账号状态和“当前账号”；敏感操作收纳到更多菜单。当前账号的确认弹窗说明重新登录影响。
