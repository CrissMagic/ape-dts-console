# 数据源搜索与分页

列表默认每页 10 条，可选 20 或 50 条。搜索框匹配名称、数据库地址、端口、数据库名和 Kafka Broker 地址，输入后短暂防抖再查询。类型筛选与搜索同时生效；搜索和修改每页条数回到第一页，数据删除后页码自动回到有效范围。

分页和搜索均在服务端执行；开发者的结果与总数只包含已获使用权的数据源。搜索使用字面子串，`%` 和 `_` 不作为通配符。空搜索展示全部有权限的数据源。

编辑器独立保存当前数据源，即使改名后不再匹配列表筛选，仍可继续编辑与测试连接。保存不清除筛选；新建或复制的来源若不满足当前筛选，可清空搜索后查看。

任务编辑继续使用原有数据源读取接口，不因列表分页而截断选项。列表新增接口为 `GET /api/data-sources/catalog?page=1&pageSize=10&q=...&type=POSTGRES`；允许的 pageSize 为 10、20、50。一个只读 SQL 语句使用同一快照计算授权范围、总数、有效页码和分页内容，无数据库迁移。
